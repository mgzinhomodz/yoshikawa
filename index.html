A Yoshikawa ESM é um bot multifuncional para WhatsApp, desenvolvido e mantido por @Mgzinho Modz, utilizando tecnologias autorizadas para automação.

O sistema recebe atualizações frequentes para melhorar funções e segurança. O uso em mensagens privadas só é permitido com contratação do plano de Bot Próprio.
